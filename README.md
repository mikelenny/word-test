# 词听 · 完全离线的英语单词听写

一个可以装到手机主屏幕的离线单词听写 PWA。打开就能练，不需要注册、不需要联网、没有广告。

- **两种模式**：看中文写英文（发音 + 拼写 + 手写板）；看英文选中文（四选一）。
- **四套词库**：高考 3500、雅思核心、四级词汇、考研词汇，共 18,594 条。
- **可调范围**：按词库、按 500 词一段选择学习范围，进度分别保存。
- **例句与查词**：答题后显示双语例句；点例句里的任意英文单词，离线查看音标和中文释义。
- **每日计划**：每天新词 5–50 个，复习上限 10–50 个；错词自动重复，按遗忘曲线安排复习。
- **随机 / 顺序**：随机模式会把中文释义相近或拼写只差 1–2 个字母的词编成 2–3 词小组，相邻考查；也可以切回词库顺序。
- **答题音效**：答对播放短促的“叮”，答错播放低沉的“duang”，由 Web Audio 现场合成，断网可用，可一键关闭。
- **完全离线**：首次打开后，应用外壳、词典和四套词库全部缓存到本机，断网可用。
- **数据自持**：学习记录只存在本机 `localStorage`，可导出 / 导入 JSON 备份。

## 一分钟用起来

### 本机预览

项目是纯静态页面，不需要构建。用任意静态服务器打开即可：

```bash
cd word-drill
python3 -m http.server 4173
```

浏览器访问 <http://localhost:4173/>。

> 不要直接双击 `index.html`。`file://` 协议下浏览器会阻止读取词库 JSON，页面会提示加载失败。

### 部署到 GitLab Pages

1. 在 GitLab 新建一个空项目，例如 `word-drill`（不要勾选自动生成 README）。
2. 本目录已经初始化 Git 并完成首次提交，只需要添加远程仓库并推送：

   ```bash
   git remote add origin https://gitlab.com/<你的用户名>/word-drill.git
   git push -u origin main
   ```

   如果拿到的是没有 `.git` 的源码副本，先执行 `git init && git add . && git commit -m "词听 v1.2.0" && git branch -M main`。

3. 仓库自带的 `.gitlab-ci.yml` 会自动把静态文件发布到 `public/`。
4. 打开项目的 **Deploy → Pages**（旧界面在 **Settings → Pages**），等待流水线变绿。
5. 访问地址通常是：

   ```text
   https://<你的用户名>.gitlab.io/word-drill/
   ```

   如果项目在群组下，则是 `https://<群组>.gitlab.io/word-drill/`。

> GitLab Pages 对免费账号通常要求项目为 **Public**；如果 Pages 没有自动开启，请到项目设置里检查 Pages 是否启用。所有路径都是相对路径，放在子目录下也能正常工作。

### 装到手机主屏幕

**Android（Chrome / Edge）**

1. 用浏览器打开上面的网址。
2. 等页面提示“离线词库已就绪”（首次需要联网下载约 3.5 MB 词库）。
3. 点右上角菜单 → **安装应用** / **添加到主屏幕**。
4. 回到桌面，点“词听”图标即可使用。

**iPhone / iPad（Safari）**

1. 必须用 **Safari** 打开网址（微信内置浏览器不行）。
2. 点底部 **分享** 按钮 → **添加到主屏幕** → **添加**。
3. 回到桌面，点“词听”图标即可使用。

安装后第一次打开仍需联网完成缓存；之后飞行模式也能正常练习。

## 发音说明（重要）

本应用不内置录音，发音调用手机系统自带的英语语音（`speechSynthesis`），所以：

- **完全离线**，不产生流量，也不上传任何内容。
- 音质和口音取决于手机里安装的语音包。
- 如果点“听发音”没有声音，请先安装英语语音：

**iPhone / iPad**  
设置 → 辅助功能 → 朗读内容 → 声音 → 英语（美国 / 英国）→ 下载。

**Android**  
设置 → 系统 → 语言和输入法 → 文字转语音输出 → Google 文字转语音 / 系统语音引擎 → 安装英语语音数据。不同品牌的菜单名称可能略有差异。

安装后在“我的 → 发音 → 试听”里点“读一下”确认。即使没有语音包，拼写、选择题、例句和查词仍然可以正常使用。

## 学习逻辑

- **每日队列**：先取到期复习词（不超过“每天复习”上限），再取当天剩余的新词，两者交错出现。
- **随机分组**：随机模式下，选题会优先把中文释义重合或拼写相近的词放进同一组（最多 3 个），整组连续出现；“顺序”模式则保持词库原始顺序。
- **每日新词**：第一次作答（包括点“不会”看答案）才计入当天新词；达到目标后，再开始练习会进入自由复习。
- **错词重复**：答错后，该词会在约 3 题后重新出现，同一轮最多补练 2 次；仍答错则留在错词本，按计划继续复习。
- **复习间隔**：连续答对后依次为 0、1、2、4、7、15、30 天；达到第 5 级视为掌握，移出错词本。
- **错词本**：按词库分别保存。可以只练错词、查看例句、手动移除；连续答对后会自动移出。
- **记录**：今日正确率、连续天数、7 天答题柱状图、词库进度、最近练习记录。全部存在本机。

> 换手机或清理浏览器数据前，请在“我的 → 备份与恢复 → 导出”保存一份 JSON。导入会覆盖当前记录。

│   ├── fetch_sources.py     # 下载原始数据（约 30 MB，不随仓库发布）
│   └── build_data.py        # 清洗并生成 data/

### 重新生成词库

```bash
# 1. 下载原始数据到 data-src/（已加入 .gitignore）
python3 tools/fetch_sources.py

# 2. 生成压缩后的 data/
python3 tools/build_data.py --src data-src --out data

# 3. 修改 sw.js 里的 CACHE 版本号，避免手机继续使用旧缓存
```

`build_data.py` 会按固定规则清洗释义、挑选例句、合并词典并写出 `data/meta.json`。生成结果可复现，但上游数据更新后内容可能变化。

### 修改前端

直接改 `index.html`、`css/style.css`、`js/app.js` 即可，没有打包步骤。改完记得提升 `sw.js` 顶部的 `CACHE` 版本号：

```js
const CACHE = "citing-v1.2.0";
```

否则已安装的旧版本会继续使用缓存。重新打开应用后，新 Service Worker 会接管；设置页也提供“检查更新”。

### 调试小技巧

- 清缓存：浏览器开发者工具 → Application → Service Workers → Unregister，再清空 Cache Storage。
- 记录位置：`localStorage` 的 `citing.state.v1`。
- 只用键盘也能练：看英文选中文时按 `1`–`4` 选项，答题后按 `Enter` 下一题。

## 隐私

- 没有账号、没有服务器、没有统计脚本、没有第三方请求。
- 词库和页面在首次加载后缓存到本机；学习记录只写入浏览器 `localStorage`。
- 导出备份由浏览器本地生成文件，不会上传。
- 卸载 PWA 或清理浏览器数据会删除记录，请提前导出。

## 已知限制

- **首次必须联网**：需要下载约 3.5 MB 词库；之后才完全离线。
- **没有云同步**：换设备请用导出 / 导入 JSON。
- **发音依赖系统语音**：没有安装英语语音包时可能无声；应用不包含录音文件。
- **手写板是自评**：在格子里写完后点“我写对了 / 写错了”，不识别笔迹。想要自动判分，可把手机输入法切换为“手写”，直接在答题框里写。
- **相近词分组是启发式的**：根据中文释义重合关键词和拼写距离自动判断，不是人工编纂的同义词表；个别分组可能不够准确。
- **词库不是权威词典**：个别释义、音标、例句可能有误或缺失，请以纸质词典 / 教材为准。
- **PWA 安装方式因浏览器而异**：iOS 只能通过 Safari 的“添加到主屏幕”，微信内需先在浏览器打开。

## 和现成 App 的简单对比

| 产品 | 免费 / 离线 | 主要能力 | 不完全符合的地方 |
| --- | --- | --- | --- |
| [AnkiDroid](https://github.com/ankidroid/Anki-Android/releases) | 免费、离线 | 强大的间隔重复，可导入共享牌组 | 需要自己找牌组、配置模板；不是为“看中文写英文 + 手写 + 例句点词”设计 |
| [墨墨背单词](https://www.maimemo.com/) | 免费版 + 内购 | 词书多、记忆算法成熟、数据统计细 | 需要账号；免费词量有上限；离线能力有限；无手写板 |
| [不背单词](https://www.bbdc.cn/) | 免费 + 内购 | 原声例句、词根词缀、拼写测试 | 需要账号 / 同步；不是完全离线；无手写板 |
| [百词斩](https://baicizhan.com/) | 免费 + 内购 | 图片记词、词书全、适合入门 | 以识词为主，不是听写优先；有账号体系 |
| [欧路词典](https://www.eudic.net/) | 免费 + 专业版 | 离线词典强、可扩充词库、生词本 | 是词典工具，不是每日听写计划；复习功能较弱 |

以上产品的功能和收费可能随版本变化，请以官网为准。它们都很优秀，但没有一个同时满足：**主屏幕图标、100% 离线、无账号、无广告、完全免费、中英双向练习、手写 + 发音 + 例句点词、每日定量 + 错词重复、可自选词库和范围**。因此这里直接做了一个专用的轻量 PWA。
