# 词听 · 完全离线的英语单词听写

一个可以装到手机主屏幕的离线单词听写 PWA。打开就能练，不需要注册、不需要联网、没有广告。

- **两种模式**：看中文写英文（发音 + 拼写 + 手写识别）；看英文选中文（四选一）。
- **四套词库**：高考 3500、雅思核心、四级词汇、考研词汇，共 18,594 条。
- **个人词汇**：两种加法——答题后点「加入个人词汇」逐个收词（已在里面的不会重复加），或者右上角上传 TXT / DOC / DOCX / PDF 批量提取。整批提取时可以手动勾选，支持 Shift 连选和按住拖动多选，例句直接使用试卷原文。完形填空里只在选项出现的词，自动对上同号空格所在的那句原文。学习范围里“个人词汇”排在最前面，点卡片可以勾选删除个别词，也可以一键清空。
- **词汇归属**：练习时题目右上角显示这个词最基础的词库归属（如高考、四级、雅思、考研）；同时属于多个词库时只显示最基础的那个。
- **可调范围**：按词库、按 500 词一段选择学习范围，进度分别保存。
- **例句与查词**：答题后显示双语例句；个人词汇使用试卷原文例句。点例句里的任意英文单词，离线查看音标和中文释义。
- **每日计划**：每天新词 5–50 个，复习上限 10–50 个；错词自动重复，按遗忘曲线安排复习。
- **随机 / 顺序**：随机模式会把中文释义相近或拼写只差 1–2 个字母的词编成 2–3 词小组，相邻考查；也可以切回词库顺序。
- **内置软键盘**：手机上可以关掉系统键盘，改用应用内英文键盘，避免联想、自动改词和候选栏挡住答题卡。手机上是接近全宽的浮空键盘，会稍微溢出答题卡底部；第一次按 `Enter` 提交并显示答案，第二次才进入下一题。
- **印刷体手写识别**：在格子里每格写一个字母，应用自动识别并判对错；格子里有淡淡的字高/基线参考线，识别时会用目标词辅助判断形近字母。识别不确定时才让你确认或重写，不再默认自己核对答案。
- **横屏可用**：装到主屏幕后跟随系统方向，不再锁死竖屏；横屏时内容可以滚动。
- **答题音效**：答对播放短促的“叮”，答错播放低沉的“duang”，由 Web Audio 现场合成，断网可用；音量可调到“小 / 中 / 大”，默认最大。
- **完全离线**：首次打开先加载应用外壳，词典和四套词库在后台逐项缓存；设置页会显示“已就绪”，断网可用。
- **数据自持**：学习记录只存在本机 `localStorage`，可以按「个人词汇 / 错词 / 学习记录 / 全部」分别导出、导入 JSON。

## 一分钟用起来

### 上传一份试卷

1. 点第一行右上角、设置按钮左边的上传图标。
2. 选择试卷文件：TXT、DOC、DOCX、PDF 都可以。
3. 应用会在本机读取文字，和四套词库对比，提取出高考 3500 里的词；高于高考的四级、雅思、考研词也会保留，并按词汇类别显示。
4. 提取完成后会最大化列出所有匹配到的词，默认全选。可以逐个取消，也可以按住 Shift 连选，或按住鼠标 / 手指滑动批量勾选；每个词的例句会使用它在试卷里的原句。完形填空的选项词（如 `55. A. withdraw …`）在原句里是一个空格，应用会用原文第 55 题空格所在的那句当例句，屏幕上保留空格，朗读时把这个词填进去。
5. 加入后会自动切到“个人词汇”。它固定排在学习范围最前面，练习方式和普通词库完全一样。
6. 题目右上角会显示词汇类别；一个词同时属于高考和雅思时，只显示更基础的高考。
7. 想删词时，点学习范围里的「个人词汇」卡片：列表里勾选不要的词（支持 Shift 连选、按住滑动批量勾选、全选 / 全不选），再点「删除选中」。要整批清空，点卡片上方的「清空个人词汇」。

> 扫描版 PDF 没有文字层，需要先用 OCR 转成文字版。所有解析都在浏览器本地完成，文件不会上传。

### 答题时收词

1. 答完一道题，反馈卡片右上角那句“已记入错词 / +10”**下面**有一颗小按钮「加入个人词汇」——原来的“下次记住”已经由它取代。
2. 点一下这个词就进个人词汇，按钮立刻变成红色的「从个人词汇中移出」；再点一下就从个人词汇里删掉，按钮变回「加入个人词汇」。
3. 不会重复添加：已经在个人词汇里的词，按钮一开始就是「从个人词汇中移出」。
4. 收进去的词会带上当前显示的释义、音标和例句；练习时看到的是试卷原句，存下来的就是那句原句。
5. 收进来的词会立刻出现在学习范围最前面的「个人词汇」卡片里，可以单独练，也可以到「我的 → 个人词汇 → 查看」批量删除（勾选 + 删除选中）。移出最后一个词等于清空个人词汇，会自动切回高考词库。

### 本机预览

项目是纯静态页面，不需要构建。用任意静态服务器打开即可：

```bash
cd word-drill
python3 -m http.server 4173
```

浏览器访问 <http://localhost:4173/>。

> 不要直接双击 `index.html`。`file://` 协议下浏览器会阻止读取词库 JSON，页面会提示加载失败。

## 发音说明（重要）

本应用不内置录音，发音调用手机系统自带的英语语音（`speechSynthesis`），所以：

- **完全离线**，不产生流量，也不上传任何内容。
- 音质和口音取决于手机里安装的语音包。
- 如果点“听发音”没有声音，请先安装英语语音：

**iPhone / iPad**  
设置 → 辅助功能 → 朗读内容 → 声音 → 英语（美国 / 英国）→ 下载。

**Android**  
设置 → 系统 → 语言和输入法 → 文字转语音输出 → Google 文字转语音 / 系统语音引擎 → 安装英语语音数据。不同品牌的菜单名称可能略有差异。

安装后在“我的 → 发音 → 试听”里点“读一下”确认。如果觉得声音怪，可以在“我的 → 发音 → 朗读语音”里换一个系统英语语音，再点“试听”；应用会优先选择系统里较自然的英语语音，并过滤掉搞怪语音。即使没有语音包，拼写、选择题、例句和查词仍然可以正常使用。

## 学习逻辑

- **每日队列**：先取到期复习词（不超过“每天复习”上限），再取当天剩余的新词，两者交错出现。
- **随机分组**：随机模式下，选题会优先把中文释义重合或拼写相近的词放进同一组（最多 3 个），整组连续出现；“顺序”模式则保持词库原始顺序。
- **每日新词**：第一次作答（包括点“不会”看答案）才计入当天新词；达到目标后，再开始练习会进入自由复习。
- **错词重复**：答错后，该词会在约 3 题后重新出现，同一轮最多补练 2 次；仍答错则留在错词本，按计划继续复习。
- **复习间隔**：连续答对后依次为 0、1、2、4、7、15、30 天；达到第 5 级视为掌握，移出错词本。
- **错词本**：按词库分别保存。可以只练错词、查看例句、手动移除；连续答对后会自动移出。
- **记录**：今日正确率、连续天数、7 天答题柱状图、词库进度、最近练习记录。全部存在本机。

> 换手机或清理浏览器数据前，请在“我的 → 数据导入导出”导出一次。个人词汇、错词、学习记录可以单独导出，也可以导出全部。

## 数据存在哪、怎么搬到另一台机器

应用没有后端，数据不在某个 `.json` 数据文件里，而是在**浏览器的 localStorage**（浏览器自己的存储目录，LevelDB 格式）。一共两个键：

| 键 | 内容 |
| --- | --- |
| `citing.state.v1` | 学习记录：每本书的进度、错词本（`progress[词库][单词]` 里的 `wrongCount` / `level` / `rightStreak` / `due`）、每日统计、历史记录、设置（每日新词数、学习范围等） |
| `citing.upload.v1` | 个人词汇：`words` 数组（单词、音标、释义、词库归属、试卷原句例句），以及来源文件列表 |

### 推荐做法：导出 / 导入 JSON

1. 旧机器：**我的 → 数据导入导出**，勾选要带走的内容——「个人词汇」「错词」「学习记录」，或直接勾「全部」。勾完点导出，得到 `citing-backup-YYYY-MM-DD.json`（只导出单项时文件名是 `citing-records-…` 这样的）。
2. 把 JSON 拷到新机器（U 盘、网盘、聊天工具传文件都行）。
3. 新机器：用**同一个网址**打开应用（例如同一个 GitHub Pages 链接），同样打开 **我的 → 数据导入导出**，勾成和文件里一致的范围，点「选文件导入」。

导入的规则：

- **个人词汇**：按单词合并，本机已有的不会重复，文件里多出来的词会补进去（连同音标、释义、例句和来源文件）。
- **错词**：按「词库 + 单词」合并，不会清掉本机其它错词，只把文件里的词标成待复习。
- **学习记录**：整份覆盖本机的进度、每日统计、历史和设置（这是“整机还原”）。

⚠️ 数据是按「浏览器 + 网址」隔离的：`http://localhost:4173` 和线上 `github.io` 的记录互不相通，手机上装的主屏幕 PWA 也是独立一份。所以导入时要在**平时用的那个网址**上操作。

### 想直接抠原始数据

在旧机器的开发者工具 Console 里：

```js
copy(localStorage.getItem("citing.upload.v1"))   // 个人词汇
copy(localStorage.getItem("citing.state.v1"))    // 学习记录 / 错词本
```

到新机器的同一个网址上：

```js
localStorage.setItem("citing.upload.v1", "粘贴刚才那串");
localStorage.setItem("citing.state.v1", "粘贴刚才那串");
location.reload();
```

注意：Chrome 的 localStorage 实际落在 `~/Library/Application Support/Google/Chrome/<配置>/Local Storage/leveldb`（Safari 在 `~/Library/Safari/LocalStorage`）。那是浏览器的内部数据库，**不建议直接拷目录**，跨机器、跨版本经常读不出来，用上面的 JSON 最稳。

```text
│   ├── meta.json
│   ├── word-index.json      # 四套词库的合并索引（判断词汇归属）

├── tools/

└── DATA_LICENSE.md
```

### 重新生成词库

```bash
# 1. 下载原始数据到 data-src/（已加入 .gitignore）
python3 tools/fetch_sources.py

# 2. 生成压缩后的 data/
python3 tools/build_data.py --src data-src --out data

# 3. 修改 sw.js 里的 CACHE 版本号，避免手机继续使用旧缓存
```

`build_data.py` 会按固定规则清洗释义、挑选例句、合并词典并写出 `data/meta.json`。生成结果可复现，但上游数据更新后内容可能变化。

### 修改前端

直接改 `index.html`、`css/style.css`、`js/app.js` 即可，没有打包步骤。改完记得提升 `sw.js` 顶部的 `CACHE` 版本号：

```js
const CACHE = "citing-v1.5.6";
```

否则已安装的旧版本会继续使用缓存。重新打开应用后，新 Service Worker 会接管；设置页也提供“检查更新”。

### 调试小技巧

- 清缓存：浏览器开发者工具 → Application → Service Workers → Unregister，再清空 Cache Storage。
- 记录位置：`localStorage` 的 `citing.state.v1`。
- 只用键盘也能练：看英文选中文时按 `1`–`4` 选项；答题后第一次按 `Enter` 提交并显示答案，第二次按 `Enter` 进入下一题。

## 隐私

- 没有账号、没有服务器、没有统计脚本、没有第三方请求。
- 词库和页面在首次加载后缓存到本机；学习记录只写入浏览器 `localStorage`。
- 导出备份由浏览器本地生成文件，不会上传。
- 卸载 PWA 或清理浏览器数据会删除记录，请提前导出。

## 已知限制

- **首次必须联网**：需要下载约 5 MB 词库与 PDF 组件；之后才完全离线。
- **没有云同步**：换设备请用导出 / 导入 JSON。
- **发音依赖系统语音**：没有安装英语语音包时可能无声；应用不包含录音文件。
- **手写识别是实验功能**：只针对印刷体，每格写一个字母，尽量写大写；连笔、草书、字母粘连或写得过小时可能识别不准。识别不确定时不会擅自判对错，会显示识别结果让你确认或重写；也可以改用内置键盘。大写 `I` / 小写 `l` 等几乎同形的字母会按目标词处理；`m/n`、`a/o` 等形近字母如果区分不开，会回退让你确认，避免把明显的拼写错误自动判对。
- **试卷提取依赖文字层**：扫描版 PDF 需要先 OCR；加密 PDF、纯图片 PDF 可能提取不到文字。老式 DOC 采用兼容性读取，复杂排版或特殊编码的文档可能漏词。
- **词汇类别按最基础词库显示**：一个词同时属于高考和雅思时只显示高考；四套词库之外的专有名词和生僻词不会收进个人词汇。
- **个人词汇的例句来自试卷原文**：如果试卷里只有单词表、没有完整句子，这些词可能没有例句；应用不会用词典例句代替。答题时点「加入个人词汇」收进来的词，会带上它当前显示的例句（含试卷原句）。全角标点（`，` `．`）会先转成半角再切句，所以中文排版导出的试卷也能切出原文句。完形填空的选项词会借用同号空格所在的原文句子，句子里的空格按原卷保留；原文空格没有编号、或题号与空格对不上时，只能靠选项本身，可能仍然没有例句。
- **相近词分组是启发式的**：根据中文释义重合关键词和拼写距离自动判断，不是人工编纂的同义词表；个别分组可能不够准确。
- **词库不是权威词典**：个别释义、音标、例句可能有误或缺失，请以纸质词典 / 教材为准。
- **PWA 安装方式因浏览器而异**：iOS 只能通过 Safari 的“添加到主屏幕”，微信内需先在浏览器打开。
