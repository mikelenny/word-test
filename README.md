# 词听 · 完全离线的英语单词听写

一个可以装到手机主屏幕的离线单词听写 PWA。打开就能练，不需要注册、不需要联网、没有广告。

- **三种模式**：看中文写英文（发音 + 拼写 + 手写识别）；看英文选中文（四选一）；词形变化（good → better / best，go → went / gone，形容词变副词、比较级、最高级、动词过去式与过去分词等）。
- **四套词库**：高考 3500、雅思核心、四级词汇、考研词汇，共 18,594 条。
- **个人词汇**：支持建多个自己命名的词汇本（比如「作文常用」「阅读生词」），名字随时可以在管理页改。三种加法——答题后点「加入词汇本」（词已经在里面时按钮变成「从词汇本移除」，有多个本就先选加到哪一本，已经在的那本显示「移除」，可以就地新建）、查词时点词汇本标签直接加、首页「手动检录」、或者右上角上传 TXT / DOC / DOCX / PDF 批量提取。整批提取时可以选目标词汇本、也能新建一个；手动勾选支持 Shift 连选和按住拖动多选，例句直接使用试卷原文。完形填空里只在选项出现的词，自动对上同号空格所在的那句原文。学习范围第二行单独列出「我的词汇本」，点卡片切库，点卡片上的铅笔进入管理与批量删词。
- **词汇归属**：练习时题目右上角显示这个词最基础的词库归属（如高考、四级、雅思、考研）；同时属于多个词库时只显示最基础的那个。
- **可调范围**：按词库、按 500 词一段选择学习范围，进度分别保存。
- **例句与查词**：答题后显示双语例句；个人词汇使用试卷原文例句。点例句里的任意英文单词，离线查看音标和中文释义，释义下面直接列出这个词的**词形变化**——规则变化和特殊变化都在里面，红色标出需要单独记的（better / best、went / gone、children、men…），点一下就能把这些变形挨个听写一遍。上传或导入的词没有释义时，会自动用离线词典的释义兜底。
- **每日计划**：每天新词 5–50 个，复习上限 0–50 个（选 0 就是今天不复习）；额度用完后继续点「开始练习」会继续加新词，想练多久练多久。一组练习按「新词 → 错词 → 复习」三轮走，每轮开头有提示，写错的词集中在第 2 轮重写一遍，不再插在新词中间；答错的词按遗忘曲线安排复习。
- **听写顺带变形**：看中文写英文时，一张卡片里把原词和它的变形一起写完。第一行是原词，下面按词性分组，一行一个变形：find 下面是「过去式 / 过去分词 found、现在分词 finding、第三人称单数 finds」；study 这种既是动词又是名词的词会分成「v. 动词」和「n. 名词」两组，study 的三单和复数同为 studies 也各占一行。规则变化和不规则变化都写。所有行一起提交，**有一行写错整题算错**，反馈里逐行标出对错。题面会把词典释义开头的 `(found, found)` 这类答案提示抹掉；点「只写原词」可以当场略过变形。首页的「听写顺带特殊变形」状态条或设置里的开关可以整体上关掉。
- **错词本**：记下每次错的细节——写错的拼写（红色划掉错的那段、标出正确的字母）、选错的选项、写错的变形（比如「最高级 best · 上次写成 baddest」），或者「直接看了答案」。顶部可以按词汇本切换，也可以看「所有」词汇本的错词；列表支持按**最近出错 / 字母 / 错误次数**排序，排序偏好会记住；支持逐条勾选、全选、批量删除。
- **随机 / 顺序**：随机模式会把中文释义相近或拼写只差 1–2 个字母的词编成 2–3 词小组，相邻考查；也可以切回词库顺序。
- **内置软键盘**：手机上可以关掉系统键盘，改用应用内英文键盘，避免联想、自动改词和候选栏挡住答题卡。手机上是接近全宽的浮空键盘，会稍微溢出答题卡底部；第一次按 `Enter` 提交并显示答案，第二次才进入下一题。
- **印刷体手写识别**：在格子里每格写一个字母，应用自动识别并判对错；格子里有淡淡的字高/基线参考线，识别时会用目标词辅助判断形近字母。识别不确定时才让你确认或重写，不再默认自己核对答案。
- **横屏可用**：装到主屏幕后跟随系统方向，不再锁死竖屏；横屏时内容可以滚动。
- **答题音效**：答对播放短促的“叮”，答错播放低沉的“duang”，由 Web Audio 现场合成，断网可用；音量可调到“小 / 中 / 大”，默认最大。
- **完全离线**：首次打开先加载应用外壳，词典和四套词库在后台逐项缓存；设置页会显示“已就绪”，断网可用。
- **数据自持**：学习记录只存在本机 `localStorage`，导出时能逐个词汇本、逐个词库的错词勾选，也能一键全选，导成 JSON 换设备导入。导入时按文件里的内容挑范围，词汇本按名字合并，换设备也不会丢。

  - 每张多行卡片上新增「只写原词」按钮，可以当场略过本题变形；首页状态条和设置开关仍然可以整体关闭变形听写。

- **v2.0.3**（2026-11-21）

  - 第 1 轮的提示分三种说法：带变形时「今天 20 个新词，顺带 1 个特殊变形」；这批词没有不规则变化时「这批词没有特殊变形」；开关关着时「变形听写已关闭」。不再让人猜为什么少了几题。

- **v2.0.2**（2026-11-21）

  - 设置 → 离线与更新里的「检查更新」会明确告诉你结果：「已是最新版本 v2.0.2」或者「发现新版本，正在更新」，不再是一句模糊的提示。
  - 同一处新增**「强制重载」**：清掉 Service Worker 与离线缓存后重新加载，学习记录（在 localStorage 里）不受影响，之后联网会重新缓存词库。版本一直上不去时用它。
  - 页面导航改成「网络优先」（2.5 秒拿不到就用缓存外壳），`index.html` 里的脚本样式带上 `?v=2.0.2` 版本号，旧缓存不会再把人钉在几个版本之前；离线时仍按不带查询串的地址回落到预缓存。

- **v2.0.1**（2026-11-21）
  - 修复 gentleman、policeman、fisherman 这类 -man 复合词的复数没被当成「不规则变化」的问题：听写 gentleman 之后，下一题就是 gentlemen。
  - 同一类漏掉的还有 -f / -fe 结尾的复数：leaf → leaves、thief → thieves、wolf → wolves、half → halves、shelf → shelves、calf → calves、scarf → scarves 现在也会跟着听写。
  - 顺带修掉 -f / -fe 复数本身拼错的 bug：以前会写成 `leves`、`thives`、`woves`、`haves`、`sheves`、`caves`（和 cave 的复数撞车）、`loves`（和 love 的复数撞车），现在是正确的 leaves / thieves / wolves / halves / shelves / calves / loaves。
  - 补了 ch 发 /k/ 的例外（stomach → stomachs、monarch → monarchs），不再写成 stomaches。
  - 补齐漏掉的不规则动词：do → did / done（以前会写成 doed）、arise、awake、dwell、knit、plead、rid、shave、slit、sow、stride、thrive、undergo、uphold、withhold、withstand、fling、bid。不规则动词表从 149 个补到 168 个。
  - 过去式和过去分词写法相同的合并成一题（shave → shaved / shaven），不会同一个答案连问两遍。
  - 规则变化仍然不额外占题：city → cities、potato → potatoes、belief → beliefs 这类只按拼写规则走的，不会插进听写。

- **v2.0.0**（2026-11-21）
  - 听写本身开始考**特殊词形变化**：听写 pay 时，下一题就是 paid（过去式 / 过去分词同形时合并成一题）；good 会跟 better、best、well，child 会跟 children。词形题紧跟在原词后面，一轮里按「pay → paid → good → better → best → well → child → children」的顺序走。
  - 只加**不规则**变化（-ed / -s / -er 这类按规则来的一眼就会，不额外占题），所以一天里只有少数几个词会多出题目，不会把一轮练习撑长。
  - 变形题题面是中文释义 + 「写出 pay /peɪ/ 的 过去式 / 过去分词」，右上角标「变形」，可以点「听原词」；判分时不规则表里的另一种写法也算对。
  - 变形题答错同样记进错词本，写明「过去式 / 过去分词 paid · 上次写成 payed」；**错词重写那一轮重写的是 paid，而不是再听写一遍 pay**，结果页的「只练这次错词」也一样。
  - 变形题不占每天的新词额度，也不会因为答对变形就把原词标成「已掌握」；轮次提示会写清楚，例如「今天 5 个新词，顺带 3 个特殊变形」。
  - 设置 → 每日学习新增开关「听写特殊变形」，关掉后听写回到只考原词；「看英文选中文」模式不受影响。
  - 顺带把答题输入区（字母格、输入框、提交 / 提示 / 不会、软键盘）抽成一份共用模板，变形题和听写不再各写一套。

## 一分钟用起来

### 上传一份试卷

1. 点第一行右上角、设置按钮左边的上传图标。
2. 选择试卷文件：TXT、DOC、DOCX、PDF 都可以。
3. 应用会在本机读取文字，和四套词库对比，提取出高考 3500 里的词；高于高考的四级、雅思、考研词也会保留，并按词汇类别显示。
4. 提取完成后会最大化列出所有匹配到的词，默认全选。可以逐个取消，也可以按住 Shift 连选，或按住鼠标 / 手指滑动批量勾选；每个词的例句会使用它在试卷里的原句。完形填空的选项词（如 `55. A. withdraw …`）在原句里是一个空格，应用会用原文第 55 题空格所在的那句当例句，屏幕上保留空格，朗读时把这个词填进去。
5. 列表顶部一行是目标词汇本：默认是上次用的那本，点别的就能改；点「新建」可以现场建一本，建完会回到这个列表，刚才的勾选都还在。
6. 加入后会自动切到那一本。词汇本排在「学习范围」第二行，练习方式和普通词库完全一样。
7. 题目右上角会显示词汇类别；一个词同时属于高考和雅思时，只显示更基础的高考。
8. 想删词时，点词汇本卡片右上角的铅笔：列表里勾选不要的词（支持 Shift 连选、按住滑动批量勾选、全选 / 全不选），再点「删除选中」。这一页还能重命名、清空词汇、删除整本。

> 扫描版 PDF 没有文字层，需要先用 OCR 转成文字版。所有解析都在浏览器本地完成，文件不会上传。

### 答题时收词

1. 答完一道题，反馈卡片里有一颗小按钮「加入词汇本」——原来的“下次记住”已经由它取代。
2. 只有一个词汇本时，点一下这个词就进去，按钮变成「已加入词汇本」；再点一下又移出来。
3. 有多个词汇本时，点按钮会先弹出「加入词汇本」面板：列出每一本、每本多少词，点哪本加到哪本，点错的再点一次就移出；面板底部还可以新建一本并直接加进去。
4. 收进去的词会带上当前显示的释义、音标和例句；练习时看到的是试卷原句，存下来的就是那句原句。
5. 收进来的词会立刻出现在「学习范围」第二行对应的词汇本里，可以单独练，也可以点卡片上的铅笔批量删除。

## 学习逻辑

- **每日队列**：第 1 轮是当天的新词，第 3 轮是到期复习词（不超过“每天复习”上限），第 2 轮等第 1 轮练完再按实际写错的词生成，所以三轮不会混在一起。
- **随机分组**：随机模式下，选题会优先把中文释义重合或拼写相近的词放进同一组（最多 3 个），整组连续出现；“顺序”模式则保持词库原始顺序。
- **每日新词**：第一次作答（包括点“不会”看答案）才计入当天新词；达到目标后，再开始练习会进入自由复习。
- **听写变形**：原词和它的所有变形（规则 + 不规则）写在同一张卡片的多行输入框里，按词性分组；任一行的答案写错，整题按错处理。点「只写原词」可跳过本题变形，首页或设置里可整体关闭。
- **错词重复**：第 1 轮写错的词不插队，统一进第 2 轮重写；自由练习和单轮练习里仍在约 3 题后重写，最多 2 次。多行题写错后，重写时仍然带着变形行。
- **复习间隔**：连续答对后依次为 0、1、2、4、7、15、30 天；达到第 5 级视为掌握，移出错词本。
- **错词本**：按词库分别保存。可以只练错词、查看例句、手动移除；连续答对后会自动移出。
- **记录**：今日正确率、连续天数、7 天答题柱状图、词库进度、最近练习记录。全部存在本机。

> 换手机或清理浏览器数据前，请在“我的 → 数据导入导出”导出一次。个人词汇、错词、学习记录可以单独导出，也可以导出全部。

## 数据存在哪、怎么搬到另一台机器

应用没有后端，数据不在某个 `.json` 数据文件里，而是在**浏览器的 localStorage**（浏览器自己的存储目录，LevelDB 格式）。一共两个键：

| 键 | 内容 |
| --- | --- |
| `citing.state.v1` | 学习记录：每本书的进度、错词本（`progress[词库][单词]` 里的 `wrongCount` / `level` / `rightStreak` / `due`）、每日统计、历史记录、设置（每日新词数、学习范围等） |
| `citing.upload.v1` | 个人词汇：`version: 2` 的 `books` 数组，每本带 `id` / `name` / `words`（单词、音标、释义、词库归属、试卷原句例句）/ `files`（来源文件列表），外加 `lastUsedId`。老版本的 `words` 单本结构会在启动时自动迁移 |

### 推荐做法：导出 / 导入 JSON

1. 旧机器：**我的 → 数据导入导出**，勾选要带走的内容——「个人词汇」下面可以逐本勾（只导某一本）「错词」下面可以按词库勾，也可以直接勾「全部」。勾完点导出，得到 `citing-backup-YYYY-MM-DD.json`；只导一本词汇本时文件名是 `citing-personal-作文本-….json`，只导一个词库的错词时是 `citing-wrong-….json`。
2. 把 JSON 拷到新机器（U 盘、网盘、聊天工具传文件都行）。
3. 新机器：用**同一个网址**打开应用（例如同一个 GitHub Pages 链接），同样打开 **我的 → 数据导入导出**，勾成和文件里一致的范围，点「选文件导入」。

导入的规则：

- **个人词汇**：按词汇本名字合并（本机没有同名本时会新建），同一本里按单词合并——已有的不会重复，文件里多出来的词会补进去（连同音标、释义、例句和来源文件）。旧备份里只有一个 `words` 数组时，会并进「个人词汇」这一本。
- **错词**：按「词库 + 单词」合并，不会清掉本机其它错词，只把文件里的词标成待复习。
- **学习记录**：整份覆盖本机的进度、每日统计、历史和设置（这是“整机还原”）。

⚠️ 数据是按「浏览器 + 网址」隔离的：`http://localhost:4173` 和线上 `github.io` 的记录互不相通，手机上装的主屏幕 PWA 也是独立一份。所以导入时要在**平时用的那个网址**上操作。

### 想直接抠原始数据

在旧机器的开发者工具 Console 里：

```js
copy(localStorage.getItem("citing.upload.v1"))   // 个人词汇
copy(localStorage.getItem("citing.state.v1"))    // 学习记录 / 错词本
```

到新机器的同一个网址上：

```js
localStorage.setItem("citing.upload.v1", "粘贴刚才那串");
localStorage.setItem("citing.state.v1", "粘贴刚才那串");
location.reload();
```

注意：Chrome 的 localStorage 实际落在 `~/Library/Application Support/Google/Chrome/<配置>/Local Storage/leveldb`（Safari 在 `~/Library/Safari/LocalStorage`）。那是浏览器的内部数据库，**不建议直接拷目录**，跨机器、跨版本经常读不出来，用上面的 JSON 最稳。

### 重新生成词库

```bash
# 1. 下载原始数据到 data-src/（已加入 .gitignore）
python3 tools/fetch_sources.py

# 2. 生成压缩后的 data/
python3 tools/build_data.py --src data-src --out data

# 3. 修改 sw.js 里的 CACHE 版本号，避免手机继续使用旧缓存
```

`build_data.py` 会按固定规则清洗释义、挑选例句、合并词典并写出 `data/meta.json`。生成结果可复现，但上游数据更新后内容可能变化。

### 修改前端

直接改 `index.html`、`css/style.css`、`js/app.js` 即可，没有打包步骤。改完记得提升 `sw.js` 顶部的 `CACHE` 版本号：

```js
const CACHE = "citing-v1.5.6";
```

否则已安装的旧版本会继续使用缓存。重新打开应用后，新 Service Worker 会接管；设置页也提供“检查更新”。

### 调试小技巧

- 清缓存：浏览器开发者工具 → Application → Service Workers → Unregister，再清空 Cache Storage。
- 记录位置：`localStorage` 的 `citing.state.v1`。
- 只用键盘也能练：看英文选中文时按 `1`–`4` 选项；答题后第一次按 `Enter` 提交并显示答案，第二次按 `Enter` 进入下一题。

## 隐私

- 没有账号、没有服务器、没有统计脚本、没有第三方请求。
- 词库和页面在首次加载后缓存到本机；学习记录只写入浏览器 `localStorage`。
- 导出备份由浏览器本地生成文件，不会上传。
- 卸载 PWA 或清理浏览器数据会删除记录，请提前导出。

## 已知限制

- **首次必须联网**：需要下载约 5 MB 词库与 PDF 组件；之后才完全离线。
- **没有云同步**：换设备请用导出 / 导入 JSON。
- **发音依赖系统语音**：没有安装英语语音包时可能无声；应用不包含录音文件。
- **手写识别是实验功能**：只针对印刷体，每格写一个字母，尽量写大写；连笔、草书、字母粘连或写得过小时可能识别不准。识别不确定时不会擅自判对错，会显示识别结果让你确认或重写；也可以改用内置键盘。大写 `I` / 小写 `l` 等几乎同形的字母会按目标词处理；`m/n`、`a/o` 等形近字母如果区分不开，会回退让你确认，避免把明显的拼写错误自动判对。
- **试卷提取依赖文字层**：扫描版 PDF 需要先 OCR；加密 PDF、纯图片 PDF 可能提取不到文字。老式 DOC 采用兼容性读取，复杂排版或特殊编码的文档可能漏词。
- **词汇类别按最基础词库显示**：一个词同时属于高考和雅思时只显示高考；四套词库之外的专有名词和生僻词不会收进个人词汇。
- **个人词汇的例句来自试卷原文**：如果试卷里只有单词表、没有完整句子，这些词可能没有例句；应用不会用词典例句代替。答题时点「加入词汇本」收进来的词，会带上它当前显示的例句（含试卷原句）。全角标点（`，` `．`）会先转成半角再切句，所以中文排版导出的试卷也能切出原文句。完形填空的选项词会借用同号空格所在的原文句子，句子里的空格按原卷保留；原文空格没有编号、或题号与空格对不上时，只能靠选项本身，可能仍然没有例句。
- **相近词分组是启发式的**：根据中文释义重合关键词和拼写距离自动判断，不是人工编纂的同义词表；个别分组可能不够准确。
- **词库不是权威词典**：个别释义、音标、例句可能有误或缺失，请以纸质词典 / 教材为准。
- **PWA 安装方式因浏览器而异**：iOS 只能通过 Safari 的“添加到主屏幕”，微信内需先在浏览器打开。
